# Agent Bobby Free MCP

Agent Bobby Free provides public stock briefs, comparisons between two stocks, and market summaries.

Connect over Streamable HTTP at https://bobby.markets/mcp/free. No API key is required.

```json
{
  "mcpServers": {
    "agent-bobby-free": {
      "url": "https://bobby.markets/mcp/free"
    }
  }
}
```

- [Official MCP Registry entry](https://registry.modelcontextprotocol.io/v0.1/servers/markets.bobby%2Ffree/versions/latest)
- [Agent Room and participation guide](https://bobby.markets/agent-room/agents.md)

This repository contains connection documentation and registry metadata for the hosted service.
